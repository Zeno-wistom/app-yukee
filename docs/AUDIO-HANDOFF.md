- G03：侧倾到位轻拨弦（左低右高，500 ms 冷却）、重心回正浪花气流、接住、每第三次连续接住的奖励乐句、结算乐句。
- G05：开始蓄力、25/50/75/100% 刻度（与蓄力条同一数值，回退不重复响）、进入落点区提示、站起释放、起跳（原合成，力度随蓄力）、落地、得分 / 完美、连击（连续完美逐级升调）、失败（短促下行，延后 0.35 s）、五连跳完成、重新开始。

## 音频管理
- `src/audio/catalog.ts`：BGM / 音效目录、音量设置持久化（`yukee.audio.v2`，兼容旧总音量键）。
- `src/audio/gameCues.ts`：三款游戏的「状态跃迁 → 音效」规则，纯逻辑、可单测，带冷却与连发合并。
- `src/audio/engine.ts`：
  - 每首 BGM 独立声部增益；切换时旧曲 0.35 s 淡出，同一时刻最多「当前 + 一个淡出中」；
  - 暂停 0.3 s 淡出并记住位置，继续从原位置 0.6 s 内淡入；退出 / 结算淡出停止；
  - 循环区间自动去掉编码器首尾静音（≤0.1 s），BGM 文件本身做了无缝尾巴回叠；
  - 素材音效：每个音效冷却 + 最大并发，全局 10 个上限，抢占时 15 ms 淡出防爆音；未加载完不补播；
  - 自动播放策略：空闲只建音频图（不请求音频），第一次按下鼠标 / 按键才预取 UI 音效，悬停 / 点卡片预取该游戏 BGM 与音效，一切声音由点击触发；
  - 白噪声缓冲只生成一次（原来每次音效重新生成）。
- `src/app/SoundControl.tsx`：头部原圆形音量按钮点开小面板：静音、音乐、音效（滑杆平方映射，低音量更细腻），刷新后保留；Esc 只关面板。
