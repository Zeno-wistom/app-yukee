- Codex 远程分支现在有两次提交：`8050408`（深蓝海面）和之后推送的 `3953e12`「bring sunny castle, solar scout and sunlight collection」。白天版**已经推送**，就在 3953e12 里。

## 3. 晴日河湾场景

底图原样使用，其上全部是程序化图层：

- 轻度压暗 + 暗角：保留阳光感，让目标和角色成为画面里对比最强的东西。
- 太阳光芒与暖光：从原画里的太阳位置发出，进度越高越亮、越长。
- 瀑布流光、河面闪光：亮度刻意压低，不和目标抢视线。
- **彩虹进度**：六束阳光对应彩虹六道色带。每接住一束，光先被吸进 Yukee，再由 Yukee 沿弧线送上天空，画出对应颜色的那一道。下一道的位置用淡虚线预告。HUD 的六个小太阳点亮后也是对应的彩虹色。
- 完成：彩虹完整发光，阳光最强，彩虹下飘起少量彩色光片；Yukee 移到彩虹下举手庆祝，结算面板放在右下，不挡角色。

## 4. 阳光目标（重做）

- **来源**：从原画的太阳出发，沿光路落到左岸或右岸上空的接光点。
- **一眼可辨**：深色径向衬底把亮背景压下去；光核是白到金的渐变，外面一圈深青轮廓；八道旋转光芒带深色描边；目标比原来的星星更大。
- **远近**：下方河面有落点光圈和光柱，说明它悬在哪里。
- **靠近时**：Yukee 天线灯和光团之间出现带深色描边的光带，光带上有流动光点；光团变大、光芒加长加快转；进度环接近时填到一半，进入接光区后填满。外侧有带描边的方向箭头。
- **接住后**：冲击环和光片，光被吸进 Yukee（Yukee 发暖光、笑眼、腮红、举手跳起），然后飞上天空画出彩虹带。
- **下一个**：回中之前，下一束阳光在太阳旁、另一侧的位置脉动等待；回到中间后才落下。

## 5. Yukee 一致性

- 以挂灯 Yukee 和 G01 像素精灵为准：深墨绿圆润胶滴、近黑轮廓、黑色面屏、薄荷发光眼、暖金天线灯，没有嘴。
- 先画到低分辨率离屏画布，再无平滑放大，和像素世界是同一种语言；光晕、光带仍然平滑绘制。
- 冲浪动作：随侧倾横移，身体和板子分别倾斜，天线有反向惯性，手臂保持平衡，侧倾时溅起浪花，板下有尾迹。
- 表情：眼睛看向目标，接近时眼睛变大，接住时弯月笑眼 + 腮红，看不到人时眯眼。角色高度约占画面 25%。
