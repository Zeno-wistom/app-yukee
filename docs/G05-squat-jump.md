# G05 浅蹲跳一跳（Hark 分支 `feature/g05-hark`）

基线：G03 v3 融合版 `52177f1`。G01 / G02 / G03 代码未改动；G04「月野风车」及其它占位卡片保持「开发中」。
选卡页第 5 张卡（原「月桥城影」占位）替换为 G05。

## 玩法
- 等轴 2.5D 悬浮方块（标准方块 / 窄方块 / 圆柱），路线在左上、右上两个方向交错，不会连续三次同向。
- 蓄力越久跳得越远，最大蓄力 1.5 秒。落点按真实距离计算，**不吸附**：
  - 落上目标台得 1 分；中心命中得 2 分，连续中心命中递增（+2、+4、+6…）；白色同心圈加分台额外 +5。
  - 跳得太轻仍在原台：不得分也不失败，可再蓄力。
  - 不够 / 过远掉落；踩到边缘会翻倒再掉落。
- 连续成功 5 次通关；失败显示结算，可「再来一局」（按钮或 Enter）或「结束活动」。
- 画面：浅灰背景、柔和粉彩方块（顶面、两侧明暗、远处投影）、白色小机器人（深色面屏 + 青色眼睛 + 薄荷天线点）。
  蓄力时机器人与平台同时压缩、脚下细小光点收拢；空翻抛物线、落地回弹、中心命中白色涟漪与「完美 +N」、镜头弹簧跟随。
- 文件：`src/games/squatJump/jumpLogic.ts`（纯逻辑）、`squatJumpScene.ts`（Canvas 绘制与动画）、`SquatJump.tsx`（控制器 + HUD）、
  `SquatCalibrationView.tsx`（校准）、`squatJump.css`。

## 输入
键盘与摄像头只是两种「按下 / 松开」来源，共用同一个控制器与 `JumpRun.jump(chargeSec)`。

**键盘演示**（校准页「键盘演示 · keyboard_demo」）：按住空格蓄力、松开起跳；Esc 暂停（暂停会清空蓄力）。
页面标注 `keyboard_demo · 非人体识别`，结果写明「不计入真实活动」，状态机只记录来源、不增加完成次数。

**摄像头浅蹲**（`src/vision/squatPose.ts`，依据《电脑端动作游戏完整交互与设计方案 10.21 V2》第 17–19 节）：
- 只读 MediaPipe 左右肩（11 / 12）的**图像坐标**，可见度 ≥ 0.65；不使用以髋为原点的世界坐标（会抵消整体下降）。
- 校准：站直 2 秒（双肩起点、肩宽 W0、静止抖动）→ 舒适浅蹲并停住约 0.5 秒（本人幅度 A，最小有效下降 max(12px, 6×抖动, 0.08 W0)）→ 站回。
- `q = ((L.y−L0.y)+(R.y−R0.y)) / 2 / W0`，`u = q / A`。
- 进入蓄力：先在站立区（u ≤ 0.2）累计 200ms，再 u ≥ 0.65 且检查项通过并稳定 0.3 秒。保持在蹲位（u ≥ 0.5）期间蓄力增长；回升途中冻结；
  回到 u ≤ 0.25 稳定 0.22 秒才释放起跳。抖动跨过单一阈值不会反复触发；保持浅蹲不会重复起跳。
- 检查项：两肩同步（位移差 ≤ 0.3A）、肩宽 0.8–1.2 W0（前探暂停）、横移 ≤ 0.25 W0、肩线侧倾 ≤ 10°。蓄力中检查失败则取消本轮、不起跳。
- 丢失双肩：< 0.3 秒冻结输入、不误释放；> 0.3 秒取消本轮并提示，回到站立区稳定约 1 秒后恢复。
- 落地后需要先站直才能开始下一次蓄力。

**限制**：这些阈值是展前起测值；沙箱只用合成关键点（单元测试）和无人画面的假摄像头验证过，**没有真人摄像头验证**。
只看双肩无法严格区分浅蹲与弯腰，正面单摄像头也不能评估膝关节动作质量。
