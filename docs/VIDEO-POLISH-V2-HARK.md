## 重新生成
```
cd video/capture && node capture-screens.mjs monitor,lamp && bash render-all2.sh
cd ../compose && node export-timeline2.mjs && python3 mix2.py && python3 compose2.py /tmp/v2.mp4
ffmpeg -i /tmp/v2.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:v copy -c:a aac -b:a 192k ../dist/YUKEE精修版产品体验演示视频-v2.mp4
```
（输出先写 /tmp：工作区文件系统上 ffmpeg 写 mp4 尾部会失败。）

## 仍未验证 / 限制

- 实体灯条颜色、亮度未实测；提醒音为合成演示音

- 人物仍是风格化人台（程序化几何），不是写实数字人；手指无逐指打字动画
- 产品侧视验收图里后盖区域的少量灰色几何伪影仍在模型中，成片镜头里看不到
