# G02 / G03 v4：流畅度与玩法变化

分支：`hark/g02-g03-v4-experience`，基于 `hark/g03-fusion-v3`（52177f1）。没有改动 master 和 Codex 分支，也没有合并任何分支。用户认可的核心体验（晴日城堡、Yukee、阳光与彩虹、坐姿侧倾、实时引导）全部保留。

## 1. 卡顿与跳动：查到的原因（有代码证据）

| # | 现象 | 代码证据 | 处理 |
| --- | --- | --- | --- |
| 1 | 整幅画面 1px「跳一下」 | v3 每帧以小数偏移、关闭平滑缩放绘制 1672×941 原画（视差 `par*0.04`），像素网格在相邻像素间来回取整 | 底图 + 压暗 + 暗角预合成为静态层（左右留视差边距），每帧只在整数坐标贴一次图 |
| 2 | 每帧填充开销大 | 每个光晕都 `createRadialGradient` + 大面积填充（每帧 8–14 次）；太阳 9 道渐变光扇；全屏暗角渐变；6 条抗锯齿粗弧线 | 光晕改为按颜色缓存的贴图；光扇半分辨率预渲染一次，每帧只摆动、缩放、调透明度；彩虹已落定的色带缓存，只有正在画的那道实时描 |
| 3 | 角色一顿一顿 | 姿态推理只有约 12Hz；v3 的一阶指数平滑在每个新样本到来时速度突变 | 横移与倾斜改为临界阻尼弹簧：位置和速度都连续，同时带出自然的惯性 |
| 4 | 偶发卡顿后角色瞬移 | 视觉步长上限 100ms，主线程卡一下后一帧补走一大段 | 视觉步长上限改为 1/30 秒：卡顿后动画按正常节奏接着走 |
| 5 | 像素 Yukee 轮廓抖 | 离屏画布以小数跳跃偏移绘制，像素化后边缘每帧换格 | 离屏原点取整，小数部分在最终贴图时补偿 |
| 6 | 角色突然横跳 | 髋部可见度在 0.5 附近闪烁时，输入在「肩线」和「躯干+肩线」两套公式间逐帧切换，出现阶跃 | 两路信号用约 250ms 时间常数交叉淡化；新增测试证明逐帧阶跃小于旧做法的一半 |
| 7 | 主线程争抢 | 人脸推理（12Hz）与身体推理（12Hz）在同一个 rAF 里同步执行，经常落在同一帧 | 同一帧只跑一个模型（身体推理顺延一帧）；体感游戏期间人脸降到约 5Hz |
| 8 | 3D 桌面与游戏抢帧 | 游戏期间 R3F 仍按显示器刷新率重绘整张桌面，含 2048 阴影贴图和环境光照 | G02/G03 及其校准期间：相机静止，桌面按需渲染约 24fps，阴影贴图冻结 |
| 9 | 尺寸抖动导致画布重建 | 每次 ResizeObserver 回调都可能重新分配画布 | 只做标记，在绘制循环里限频处理（180ms）；≤2px 的变化忽略 |
| 10 | 低端机持续掉帧 | — | 自适应渲染分辨率：连续约 2 秒帧间隔 >22ms 就降一档（1 → 0.85 → 0.7），只降不升，避免来回切换 |

其他：
- 底图在 `decode()` 完成后才交给画布，避免首帧在主线程同步解码 2MB 的 PNG。
- 画布组件加了 `memo`，HUD 每 80ms 重渲染时不再连带它。
- 2D 上下文改为 `alpha:false`。
- 暂停 / 丢失追踪时冻结的行为不变。

## 2. 实测（云端沙箱，无 GPU）

- **场景单帧绘制**（`scripts/sun-surf-bench.html`，每帧强制栅格化，180 帧）：
  - 1920×940：平均 24.7 ms、p95 42.2、最大 70.9 → 平均 11.1 ms、p95 14.2、最大 18.4
  - 1280×627：平均 10.1 → 5.5 ms
- **实际产品里 G03 演示 6 秒的 rAF 帧间隔**：
  - v3：157 帧，p50 33.4 ms，p95 50，最大 66.7，超过 50ms 的 7 次
  - v4：329 帧，p50 16.7 ms，p95 33.3，最大 50，超过 50ms 的 0 次
- **限制**：沙箱是 Linux arm64、2 vCPU、软件渲染；测试时 WebGL 绘制调用被置空，也没有真实摄像头，所以 MediaPipe 推理耗时没有实测。Windows GPU、真实摄像头和高刷屏上的效果需要你实机确认。上面的数字只能说明相对改善，**不代表已经彻底解决**。

## 3. G03：六束阳光六种形态

判定、阈值和左右交替完全不变，只改来访形态；每种都保留「深色衬底 + 深青轮廓」，保证一眼可辨。

1. 阳光光团：从太阳落下。
2. 蒲公英光絮：六粒光絮环绕光核，越靠近收得越紧。
3. 光羽小鸟：从画面侧边飞来，翅膀拍动随靠近加快。
4. 彗星光团：从上方角落划入，拖着青色彗尾。
5. 河面光泡：从河面升起，带彩虹泡膜。
6. 终章 · 大太阳：更大的阳光，外圈有十二颗彩虹光点。

- 下一束会在它自己的来处、另一侧等待。
- HUD 上显示本束的形态名，切换时轻轻弹出。

## 4. G02：五次光之访客

原有萤火虫层保留，另外叠加一层「光之访客」，动作不变：展开双臂时访客飞向帆，回位收集后被送进船灯，下一波从别处登场。

1. 月光球：从月亮落下的一颗大光球。
2. 萤火虫群：14 只，从左侧树林盘旋飞来。
3. 流星光团：从右上划入，拖着长尾。
4. 河灯：四盏小河灯从水面升起，飞到帆上。
5. 终章 · 群光：流星、萤火虫群和河灯一起来，月亮光晕逐步变亮。

- HUD 显示本波名字。
- 暂停或丢失身体时，访客随原有的时钟一起冻结。
