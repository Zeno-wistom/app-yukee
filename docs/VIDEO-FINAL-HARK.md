## 2. 外观修正（最重要）
- 几何只来自 3dm 的装配组 C：只做 mm→m 和 Z-up→Y-up 换算，不拉伸，不改屏幕或摄像头位置。安装方式与样片相同：外壳底面压在显示器顶面，灯条后沿对齐面板前表面。
- 材质依据海报：
  - 机身（殼）与灯条（燈罩）：拉丝不锈钢银灰，金属度 1，粗糙度 0.30 / 0.34，颜色是中性灰 `#c3c4c5` / `#b9babb`；
  - 屏幕：深色玻璃；
  - 摄像头：黑色镜头，外圈金属环来自模型本身的分件；
  - 后盖：磨砂乳白，透出暖光；
  - 灯条底部扩散板：默认暖白。
- 防止变蓝：环境光用中性 RoomEnvironment，补光由 `#dfe8ff` 改为中性 `#f4f1ec`。材质验收图覆盖正面、顶部、两侧、背面、摄像头，以及暖光、提醒粉紫光、侧窗日光三种光照。
- 灯光逻辑以海报为准：「先柔和呼吸，再给出更明确的颜色提示」，即暖白 → 呼吸 → 蜜桃 → 粉紫。用户点击「开始活动」后恢复暖白；游戏成功时灯光轻微增亮；回到办公后保持暖白。

## 3. 场景与人物
- 尺寸基准：桌高 0.74 m；27 英寸显示器，可视区 0.597 × 0.336 m，底边离桌面 0.115 m；键盘 0.36 m。YUKEE 用 3dm 原始尺寸（灯条约 0.35 m）。人物身高约 1.75 m，头身比约 1 : 7.4；上臂 0.29 m、前臂 0.265 m，手长约 0.185 m、掌宽 0.084 m（成人中位数）。坐姿时骨盆离桌沿 0.26 m，肘部自然弯曲，双手落在键盘上；站立活动位离显示器约 1.1 m。
- 人物是程序化人台加两骨 IK，这一版新增：
  - 带四指和拇指的手，掌心朝向随前臂自动调整；
  - 三角肌、耳、鼻、眼、眉、嘴，用来看清头部朝向；
  - 躯干侧倾；
  - 肘部方向控制（揉脖子时肘部抬起）。
- 办公动作：打字、使用鼠标、看笔记、调整坐姿；时间流逝时上身前探，然后揉脖子；提醒出现后抬头看 YUKEE、靠回椅背、点头，再握鼠标点「开始活动」；随后起身后退一步，椅子被推开。
- 游戏动作全部由真实事件日志驱动（成片时间 = 源时间 + 段偏移）：
  - G01：↑ / ↓ / ← 对应抬头 / 低头 / 左转头；
  - G02：从按下到 `data-charged` 缓慢展开双臂，从松开到计数回位；
  - G03：从按下到计数向目标侧倾，松开后回中；
  - G05：press 时到达浅蹲，蓄力中继续下沉，release 时站直并踮脚。
- 环境：侧窗日光在时间流逝段角度变低、色温变暖；灯条聚光照亮键盘区，提醒时桌面出现粉紫色光；阴影贴图 2048；ACES 色调映射。

## 5. 版式规范
- 安全边距 64 px。字体只用 Noto Sans CJK SC 一个字族，中英文同族，避免混排间距异常。字号层级：kicker 22（品牌紫 `#6E56CF`，字距 2）/ 标题 46 Bold / 正文 26；时钟标题 56。
- 三维镜头：标题块统一在左下（x = 96，底边 = 1080 − 82），进出场为 0.35 s 淡入加 12 px 位移，下方有柔和暖白渐隐底。
- 游戏段：游戏画面等比缩放 0.7 倍（1344 × 756，不拉伸），左对齐到安全边距；右栏是 3 : 4 的人物视角（400 × 533）。人物视角与游戏画面顶边对齐，右栏文字块底边与游戏画面底边对齐。顶部是章节和进度条，底部是演示输入说明。四款游戏用同一版式，由全屏匹配转场缩放进入。
- 品牌紫只用于 kicker、进度和背景弧线，不用于产品机身。

## 6. 声音
- 全片一首背景音乐：Flowerbed Fields（OpenGameArt，CC0）。G01 原曲版权待确认，没有使用。
- 四款游戏的交互音效都是录制时音频引擎的真实输出（录制时音乐音量设为 0）。
- 选择页 UI 音效来自真实录制；「开始活动」点击用产品 `ui-click.wav`；完成音效用产品 `g05-complete.wav`（Kenney CC0）。
- 演示合成音（产品里没有）：键盘声、YUKEE 提醒两音和变色提示音、转场气流声。
- 响度归一到约 −16 LUFS。

## 8. 复现
```bash
cd /workspace/work/hark-video-demo
npx vite --host 127.0.0.1 --port 5188 --strictPort &   # 真实应用（基线代码）
npx vite --config video/vite.config.ts &               # 三维场景 / 组件录制页（:5290）
cd video/capture
for g in g01 g02 g03 g05 select; do node capture-games.mjs $g; done   # 真实游戏录制
node capture-screens.mjs                                              # 主屏界面 + YUKEE 小屏
./render-all2.sh                                                      # 三维镜头与人物视角
cd ../compose
node export-timeline2.mjs && python3 mix2.py && python3 compose2.py ../dist/out.mp4
ffmpeg -i ../dist/out.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:v copy -c:a aac -b:a 192k "../dist/YUKEE最终产品体验演示视频.mp4"
```
- 时间与镜头：`video/src/timeline.mjs`（GAMES、SHOTS、CUES）。
- 动作：`video/src/scene.ts` 的 `poseAt()`。
- 版式：`video/compose/compose2.py`。
- 混音：`video/compose/mix2.py`。
- 依赖：Node 22、Chromium、FFmpeg，以及 Python 包 pillow、numpy、rhino3dm、trimesh。没有使用付费服务。
- 没有用 Remotion：环境里没有安装它，也没有对应 skill。这里用 Three.js 逐帧确定性渲染，加上 PIL 合成和 FFmpeg，同样满足逐帧可复现。
