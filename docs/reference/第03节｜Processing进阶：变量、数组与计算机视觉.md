# 核心知识与练习

## 1\. 变量、文字与条件判断

- **int 与 float：**`int` 适合整数变化；`float` 适合更细微的变化。但部分命令只接受整数。

- **String 与 ****`text()`****：**String 把信息当作文字而不是数值；`text()` 用“内容、x、y”三个参数显示文字，坐标以文字左下角为基准。

- **赋值和比较：**`=` 用于赋值，`==` 用于判断是否相等；`&&` 表示“并且”，`||` 表示“或者”。

- **`if`****：**条件为真时运行对应代码；可配合 `else` 处理另一种情况。

## 2\. 数组：把一组变化放进同一个抽屉柜

- **数组是什么：**同一类型的一组变量；数组长度为 7 时，下标是 0–6。

- **课堂例子：**预先定义 7 种背景色，用计数器驱动数组下标；超过 6 时归零，再以 1000ms 的间隔切换颜色。

- **交互细节：**需要“一次点击只切换一次”时，用 `mouseReleased()`，不要用持续触发的 `mousePressed()`。

## 3\. 声音与计算机视觉：把输入转成视觉反馈

- **Sound：**安装 Processing Foundation 的官方 Sound 库，打开 Audio Input 示例；将音量对应的圆形大小作为阈值，达到阈值时切换背景色。Minim 是更强的第三方库，课后可自行探索。

- **Video 与 OpenCV：**分别安装 Video Library 与 OpenCV for Processing；OpenCV 可识别图像或摄像头中的人脸／特征。

- **静态与实时的差别：**静态图片只需识别一次；摄像头画面不断变化，须在 `draw()` 中持续读取画面并检测人脸。

- **课堂延伸：**把自定义图片放进项目的 `data` 文件夹，并按检测到的人脸位置和尺寸覆盖图片。

# 这节课真正需要记住的东西

1. 变量负责储存与驱动变化；数组负责管理一组同类型的数据。

2. 交互不是“加特效”：输入、条件判断与视觉反馈必须形成清楚的因果关系。

3. 声音和摄像头是可用的输入源；第三方库要先安装、导入，再初始化和调用。

4. 阶段展示的价值不只是汇报，而是让真实观众体验并给出下一轮迭代证据。
