分支：`hark/g03-experience-v2`（基线 `d39870129855c8ef8afaf2ca988ac351c3a8f994`）。内部 `gameId = leanSurf` 不变，展示名「星海冲浪 / LEAN SURF」。

## 1. 原版最主要的卡点（代码诊断）

| 卡点 | 原实现 | 对普通用户的影响 |
| --- | --- | --- |
| 取景苛刻 | 双肩 + 双髋都必须可见，可见度 ≥ 0.65 | 坐在桌前时髋部常被桌沿挡住，直接无法开始 |
| 校准繁琐 | 可见 1s → 中立 2s → 左倾保持 → 右倾保持 → 回中 3s 倒计时；任一帧抖动 > 0.035 rad（约 2°）就重来 | 至少 7–8 秒，呼吸晃动就反复归零 |
| 有效幅度偏大 | 触发阈值 = 个人最大幅度的 65%，并保持 600ms | 校准时倾得越认真，游戏里要倾得越大 |
| 回中严格 | 回到 20% 以内并保持 400ms 才算一颗 | 「已到达」后还要再做一次精确动作才得分 |
| 巡航等待 | 每颗星后强制巡航 4.2s，期间动作无效 | 玩家以为没识别到，6 颗中有 25 秒在等 |
| 反馈不足 | 只有目标圆环和小像素 Yukee；看不到「我的动作被识别了多少」 | 不知道是动作不对还是没识别 |
| 掉线恢复重 | 丢失 300ms 即暂停，恢复需回中稳定 1s + 3s 倒计时 | 一次手臂遮挡就要等 4 秒以上 |

## 2. 识别与操作（`src/vision/leanPose.ts`）

- **信号**：只用身体关键点。肩线倾角（11/12 号肩点，右肩低 = 向右）为必需；双髋可见时再算「肩中点→髋中点」躯干角，两路归一化后 62% / 38% 融合。鼻子、眼、耳完全不参与；整体平移不改变两种角度。
- **一步校准**（`LeanCalibrator`）：看见双肩后自然坐好约 1 秒即可，容差约 3.4°（呼吸不会重来）；只记录中立基线，不做左右校准、不倒计时。
- **幅度**：默认满量程约 6°，接星阈值 0.42 → 约 2.5° 的轻微侧倾即可；幅度自适应**只放大不缩小**，上限约 9.5°。
- **动作循环**：朝目标侧进入接星区并保持 220ms 即接住；接住后必须回到中线附近（|u| ≤ 0.22）下一颗才开放。没有巡航等待。
- **防误触**：EMA 平滑 110ms、显示死区 0.06、单帧跳变 > 0.35 rad 丢弃；一直歪向同一侧最多 1 分；方向错误、闪动 < 220ms 不计分；中立基线漂移跟随只在靠近中间时生效（不可能凭空触发）。
- **遮挡恢复**：600ms 内短暂丢失只冻结；超过后显示「看不到你的肩膀了」，重新看到 0.45 秒即继续，无倒计时。看不到时时间与计分都冻结、不补算。髋部中途被挡自动切到肩线，不中断。
- **首次引导**：底部面板有会动的侧倾小人、一句话指令（「像被海风吹一样，上身轻轻往左歪一点」→「再往左一点点」→「接住它…保持一下下」→「接住了！回到中间，下一颗在右边」）和实时「侧倾识别条」（圆点就是你的身体，金色区就是接星区）。

## 3. 视觉与玩法（`src/games/starSeaScene.ts` / `LeanSurfScene.tsx` / `LeanSurf.tsx`）

全部程序化 Canvas 2D 绘制，无外部图片、无运行时网络资源。

- 远景：夜空渐变、极光带、闪烁星点、月亮与光晕、细长云絮。
- 中景：远岛剪影、**中央灯塔岛（目的地）**——每接一颗星灯塔更亮，开始旋转光束；灯塔上方 6 星位**星座**，接住的星沿弧线飞上去点亮并连线。
- 海面：透视浪线向镜头推进、月光倒影、浮游光点、左右灯笼浮标（目标侧亮起）。
- 目标星从灯塔方向的海天线飞来，停在接星区；玩家越靠近，星越亮、Yukee 与星之间出现光带、进度环先填一半，进入接星区后填满；方向箭头提示往哪边。回中阶段下一颗星在海天线上闪烁等待。
- Yukee：放大约 3 倍的矢量胶滴机器人（与挂灯 Yukee 同色系），随侧倾平移、身体与冲浪板倾斜，天线惯性摆动，眼睛看向目标、接近时变大、接住时弯月笑眼 + 腮红 + 举手跳起、看不到人时眯眼；尾迹与侧倾浪花。
- 完成：6 星连成星座，灯塔全亮、星光烟花，Yukee 滑向灯塔；结算「灯塔亮了，星海被你点亮。」。
- 暂停 / 软上限弹窗 / 丢失追踪时场景时钟停止，整个世界冻结。

## 6. 未验证 / 风险

- **真人摄像头未验证**：沙箱没有摄像头，只用了合成关键点与键盘演示。阈值（约 2.5° 触发、220ms 保持）来自几何推算，真人需实测。
- 肩线角对「单侧耸肩」也会响应（属于肩部动作，符合「躯干或肩部驱动」，但可能被当作捷径）。
- 用户校准时如果本身歪坐，一侧会更容易、另一侧更难（交替规则保证静止最多 1 分）。
- MediaPipe 在深色衣服、背光、宽松外套下肩点抖动未知；离摄像头过远（肩宽 < 画面 6%）会被拒绝。
- 镜像方向按原工程约定（原始帧未镜像）；若某台电脑摄像头驱动输出已镜像，左右会反，需要真机确认。
- 场景绘制在沙箱软件光栅下约 14ms/帧（1280×720）；正式画布为 1152×648，桌面 GPU 预计远低于此，但未在用户 Windows 机器实测帧率。
