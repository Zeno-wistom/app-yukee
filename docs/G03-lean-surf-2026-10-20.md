# G03「躯干重心冲浪」本轮交付与验收

## 现在能玩什么

本地预览：<http://127.0.0.1:5173/>。开始体验 → 挂灯「开始活动」→ 第三张「躯干重心冲浪」→「开始这个活动」。

- 正式路径：双肩与双髋稳定可见 1 秒 → 中立姿态 2 秒 → 舒适左倾、右倾各稳定采样一次 → 回中准备 3 秒。任一髋部不可见，不允许进入正式游戏。
- 无合适取景条件时点击「键盘演示 · 非人体识别」：按住左右方向键侧倾，松开回中。结果明确标记 `keyboard-demo`。
- 目标左右交替共 6 次，左右各 3 次。到达并保持只标记到达，回中稳定后才点亮进度星。目标之间缓慢航行 4.2 秒，鼓励自然回中和休息；本轮合成演示实测有效时间 37.8 秒，不代表真人时长已验证。
- 没有死亡、扣分或动作幅度奖励。45 秒未完成提供继续或结束，冻结等待决定，不自动显示成功。
- `Esc` 暂停/恢复；恢复先中立稳定 1 秒，再准备 3 秒。主动退出复用现有退出弹窗；后续恢复按原系统约定重新校准并开始一局，不承诺恢复半个动作。

## 识别规则

`src/vision/leanPose.ts` 是 G03 识别与阈值的唯一实现：

- 只使用 Pose 11/12 双肩和 23/24 双髋，置信度缺失或低于 0.65、关键点出界、无效像素尺寸均拒绝。
- 先换算视频像素，计算肩中点 S 和髋中点 H，然后 `atan2(S.x - H.x, H.y - S.y)`。镜像符号只在 `measureLean` 校正一次，与镜像预览方向一致。
- 校准记录 `a0/aL/aR`，两侧分别归一化，夹到 `[-1,1]`。端点需相对中立有可分辨的约 3.4°差异且连续稳定；这只是拒绝静止噪声的下限，不要求达到某个大角度，也不给大动作额外奖励。
- `u` 按 100ms 时间常数平滑；目标侧阈值 0.65，连续 600ms 到达；回中阈值 0.20，连续 400ms 后得分。同侧长时间保持不连续得分。
- 无效帧立即冻结输入与有效时间；超过 300ms 丢失则取消半动作并暂停。恢复必须中立稳定约 1 秒和 3 秒准备，不能补算掉线动作。超过 200ms 的旧 Pose 帧视为无效；视频彻底停帧时因此还有最多 200ms 的过期检测窗口。
- 鼻子与脸部中心从未作为 G03 计分输入；肩髋共同水平平移不会改变中点连线角度。
