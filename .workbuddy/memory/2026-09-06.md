## 第四批：Pixel Yukee 重做 + 融球分裂动画重做 + 受伤表情池

  - gooey-react：peer 仅支持 React 16/17，且 SVG filter 每帧重算正是拖帧根因。

    「鼓起→析出→软连接→拉伸→断开」一次性导演序列。
  - 最终：移植 fluidkit（MIT）的 metaball 几何核心（bridgePath 张力桥 /

- **YukeeCast 三段式重写**：
  1. 起点：SVG 双 path（halo+core）真 metaball，每帧只更新 d 属性；
     断开由回滞物理自然发生，本体 elastic 回弹。
  2. 中段：轻量光核纯 transform 飞行；贝塞尔控制点钳制在挂灯∪显示器包围盒内。
  3. 终点：光球压缩→像素结晶→ripple，游戏舞台渐亮呼吸（原有，保留）。
  - 删除旧 bridge（blur+mix-blend-mode）、trail blur、source glow——拖帧根因。
