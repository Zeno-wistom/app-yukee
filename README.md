# YUKEE · 一起动一动

浏览器直接进入四款体感游戏的选择页；游戏铺满网页可用舞台，不再加载外部桌面、显示器或挂灯模型。

## 启动

需要 Node.js 20.19+ 或 22.12+；本机已使用 Node.js 24.19.0 和 Chrome 验证。

```powershell
npm install
npm run dev -- --port 5188 --strictPort
```

打开 http://127.0.0.1:5188/ 。模型、WASM、图片与声音全部随项目提供，无运行时 CDN 依赖。首次安装依赖需要网络。

```powershell
npm test
npm run build
npm run test:e2e
```

生产预览：`npm run preview`，打开 http://127.0.0.1:5189/ 。静态交付目录为 `dist/`，须完整保留其中的资源和 `mediapipe/`，部署时摄像头页面需 HTTPS（localhost 本地预览除外）。

## 体验顺序

1. 点击左右箭头或游戏目录，查看动作提示，点击「进入游戏」。
2. 允许摄像头并完成个人校准。选择页不会主动申请权限。
3. 四款校准页均提供明确标记的「键盘演示」，适合无摄像头演示；不计入真实体感活动。
4. 顶部统一暂停/返回；`Esc` 暂停或继续。退出结束本局并释放摄像头，重开会重新校准。
5. 游戏完成页返回选择，可以直接进入另一款。

| 游戏 | 摄像头动作 | 键盘演示 |
| --- | --- | --- |
| G01 拾光跑者 | 抬头跳、低头躲、左右转头收能量 | ↑ / ↓ / ← / → |
| G02 展翼接光 | 缓慢展开双臂、保持、回位，共 5 次 | 先松开按键待机片刻，再按住空格展开，松开回位 |
| G03 星海冲浪 | 躯干向阳光轻微侧倾，接住后回中，共 6 次 | 按住 ← / →，松开回中 |
| G05 浅蹲跳一跳 | 舒适浅蹲蓄力、站直起跳，共 5 次；双脚无需离地 | 按住空格蓄力，松开起跳 |

G05 按 D 或在地址后加 `?g05debug=1` 查看数值诊断。仅记录内存中的姿态数值；画面不保存、不上传。
摄像头独立预检：`/#vision`，退出或停止时释放轨道。
