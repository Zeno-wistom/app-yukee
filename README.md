# Yukee · 屏幕挂灯机器人 3D 交互 Demo

## 运行

需要 Node.js 20.19+ 或 22.12+。本次使用 Windows / Node.js 24.19.0 / Chrome 验证。

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5173/ 。模型与 WASM 已包含在 `public/mediapipe/`，运行时不依赖 CDN。首次安装依赖需要网络。断开外网时保持本地 Vite 服务运行。

## 体验顺序

1. 点击唯一入口「开始体验」，经过 2.65 秒连续镜头推进进入第一人称。主动活动与课堂提醒快捷入口都位于挂灯 HOME；电脑主屏只保留办公内容和后续游戏。
2. 弱提醒点「继续工作」→ 1.5 秒演示延迟 → 二次提醒。
3. 二次提醒点「稍后」→ 1.5 秒演示延迟 → 强提醒。
4. 开始活动 → 准备好了 → 面对屏幕完成本地摄像头自然姿态校准。
5. 校准完成后，挂灯中的 Yukee 本体保持原位，只析出一颗融球式分身进入电脑屏幕，并在游戏世界结晶为像素 Yukee。
6. 抬头跳、低头蹲、左右转头收集能量；完成页 → 返回工作。可重复演示。

提醒页不会自行按时间升级，必须先点击「继续工作」或「稍后」。

挂灯「开始活动」进入 GAME SELECT：Head 模式左右转头切换，Hand 模式左右挥手切换，两种模式都用点头确认。游戏右上可暂停、左下可退出，存档仅在内存中，刷新后清空。所有假输入按钮默认隐藏，按 D 或点右下角滑杆图标打开演示面板。返回桌面会拉回产品展示镜头。

Yukee Run 使用基于自然场景参考图重绘的像素背景，并拆分为场景底图、白云、远景色带、草坡、前景花草和可玩地面 6 层视差。挂灯本体在游戏期间保持 attentive / playful 联机陪伴，成功、失误、丢失识别和完成都会与像素分身同步反馈。

## G02 · 展翼接光（Winglight）

挂灯「开始活动」→ 左右切到第 2 张「展翼接光」→ 点头确认 → 个人动作校准（双肩/双肘/双腕入镜 → 保持准备姿势约 2 秒 → 缓慢展开到舒适幅度）→ 3 秒倒计时 → 开始。

- 双臂缓慢向两侧展开，稳定约 0.7 秒；再慢慢回到准备位、停稳约 0.5 秒，计 1 次。
- 只有两侧都展开才算数：单手挥动、保持展开不动、原地不动都不会加分。
- 五次充满光能后显示完成页（有效时间 + 5/5）→「回到专注」返回工作态。
- `Esc` 暂停/继续；画面右上角可暂停与退出；识别丢失会自动暂停计时与计数，恢复后需先站稳约 1 秒。
- 单局约 30–40 秒；有效时间超过 45 秒可选择继续或结束本次。
- 开发者演示：校准页右下角「开发者演示 · 键盘控制」，按住空格 / ↑ 模拟展开。演示结果带明显标识，不会被记为摄像头识别完成。

G02 与 G01 共用同一条摄像头流（不会抢占设备）；身体关键点使用本地 `public/mediapipe/pose_landmarker_lite.task`，推理全部在浏览器内完成，画面不保存、不上传。

## 摄像头预检

从演示面板进入「摄像头技术预检」，或直接打开 http://127.0.0.1:5173/#vision 。点击「启用真实摄像头」后申请权限。视频、人脸数、关键点、FPS、推理耗时与 yaw/pitch 会显示；「停止摄像头」或离开预检页会释放视频轨道。

画面不存储、不上传。预检独立于游戏；主体验使用真实摄像头姿态控制，演示面板中的调试按钮仅用于课堂无摄像头环境下的旁路验收。

## G03 · 躯干重心冲浪（Lean Surf）

开始体验 → 挂灯「开始活动」→ 用鼠标切到第三张「躯干重心冲浪」→「开始这个活动」。正式入口需双肩与双髋可见，经过中立、舒适左右侧倾校准与 3 秒准备。按目标方向缓慢侧倾，保持后回中才点亮一颗星；左右各三次，共六颗。`Esc` 暂停/继续，掉线会暂停并要求重新稳定与准备。45 秒未完成可继续或结束，不自动成功。

无法完整取景时，保留「键盘演示 · 非人体识别」：按住 ← / → 侧倾，松开回中。演示结果不会被视为真人识别验证。取景、误触与真实小屏/RGB 仍待实测，具体见 [G03 验收报告](docs/G03-lean-surf-2026-10-20.md)。
